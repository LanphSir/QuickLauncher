## v0.6+ — 探索项

- 插件级快捷键（manifest `hotkey` 直接唤起某插件）
- 多视图尺寸：插件可申请不同面板尺寸（`appapi.window.setSize`，需权限）
- 插件视图缓存 LRU 上限
- 手册：整目录导入（当前为多选文件）、在线手册源（远程拉取 + 校验 + 缓存）
- 跨平台（macOS：快捷键/托盘/通知 API 差异盘点）
- 兼容 uTools 插件协议的适配层（视用户量再评估）
